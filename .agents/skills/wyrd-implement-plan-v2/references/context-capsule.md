# Worker context capsule

Give each worker one concise, root-issued assignment. It narrows rediscovery;
it does not replace repository or task authority.

Include:

- task ID, packet path, approved plan path, and accepted baseline SHA;
- parent requirement and decision IDs plus the task's exact observable outcome;
- allowed/prohibited scope, write boundary, dependency status, and task
  worktree/branch path;
- resolved owners, callers, consumer seams, fixtures, relevant architecture
  references, and verification commands already inspected by the root;
- required skills, verification-token rule, and explicit material stop
  conditions;
- any root-accepted material-authority correction, its canonical plan or task
  location, fresh rehearsal identity, and the prior authority it supersedes;
- known rehearsal discoveries that are private implementation work, clearly
  labelled `bounded correction`; do not make the worker rediscover them or
  mistake them for authority gaps.

The worker reads the task, required Wyrd authorities, and current source before
editing. It treats the capsule's paths and facts as a starting map, corrects
stale private mechanics in task evidence, and returns only a material mismatch
to the root. A missing private interface is not material when it can be added
inside the named owner without changing the approved invariant. It may retain
learned repository context across later assignments, but always confirms the
assigned branch, base SHA, and packet before work.
