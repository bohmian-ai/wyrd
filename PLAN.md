# PLAN

Active implementation planning happens in this repository. Use the repo-local
`wyrd-plan` skill and save approved plans under:

```text
.dev/plan/<slug>/implementation-plan.md
```

Every plan contains one or more implementation-ready Terra/Luna task packets
under `.dev/plan/<slug>/tasks/`. Packets execute through the repo-local
`wyrd-implement` skill.

`.dev/` is a local, gitignored planning workspace. Current product and protocol
authority remains in `architecture/wyrd-design.md`,
`architecture/wyrd-doctrine.mdx`, and the implementation itself.

Older design dialogue, predecessor research, and session history live in
[`wyrd-plan`](https://github.com/wyrd-ai/wyrd-plan) (private, org-internal).
Treat that repository as historical evidence, not current implementation
authority.

- **Plan repo:** `github.com/wyrd-ai/wyrd-plan`
- **Current session:** none
- **Target CHANGELOG slug:** none

See `wyrd-plan/README.md` only when historical dialogue or older session
context is needed.
