All alias access stays on the original alias index. Invocation consumes the same shared view and retains the prior run/gateway logic.

Sibling consumers inspected include shared typed accessors, generic get, Run.invoke, Python eager holder hydration and typed accessors, TS typed/generic wrappers, CLI lifecycle assertions and Python authored Agent round trips.
