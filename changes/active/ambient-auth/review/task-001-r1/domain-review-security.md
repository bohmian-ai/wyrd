## Findings

### SEC-001 — MISSING: external MCP authentication consumer remains on the removed helper

- Obligation: AC-006 requires `wyrd-example-ts` to use its one WyrdClient's httpAuth for both OpenAI and MCP; REQ-002 removes the standalone helpers with no alias.
- Exact location: external candidate `b283666df93a32cb73aa8c07f881d9271797dff0`, `scripts/investigate.ts:9` imports `wyrdFetch`, and lines 22–24 construct `MCPServerStreamableHttp` with `fetch: wyrdFetch()`.
- Reachability and evidence: `package.json` exposes this file as `npm run investigate`; `tsconfig.json` includes `scripts` in typechecking. It imports the changed `gateway` from `src/agent.ts` and uses that OpenAI client alongside its own unchanged MCP transport. The reviewed Wyrd SDK no longer exports wyrdFetch. Thus this is an active sibling consumer of the migrated model client, not an absent MCP feature. My initial report incorrectly limited external consumer discovery to `src`; this report corrects that factual coverage error.
- Observable consequence: with the reviewed SDK the investigator fails at the removed import instead of discovering/calling Wyrd MCP tools. Retaining the old vendored SDK cannot validate the migrated example either, because the new OpenAI path needs httpAuth. This is a broken authentication integration/public-contract migration, not an authentication bypass.
- Smallest testable correction: reuse the same WyrdClient for the example's model and MCP consumers and replace this standalone helper with its httpAuth. Make the example consume a package projection matching the reviewed SDK; preserve the existing read-only tool filter. Typecheck the complete external example, including scripts, and exercise the investigator's MCP connection against Wyrd. No new adapter, credential chain, alias or permission change is needed.

No reachable permission widening, tenant identity substitution, provider-key forwarding caused by the new transports, duplicate credential path, credential logging in changed production code, or new durable client-side authentication behavior was established.

Skipped: independent test execution and external example build. Risk: the external investigator is not migrated to the reviewed authentication contract.
