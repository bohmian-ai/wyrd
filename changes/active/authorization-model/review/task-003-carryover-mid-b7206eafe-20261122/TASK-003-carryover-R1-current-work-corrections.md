# Correct the implemented signup and admission lifecycle

A person who has proved a mailbox or provider identity must be able to finish and safely retry the approved creation workflow, while admission, ownership and the persistent workspace cap remain effective through cleanup, proxying and supported key maintenance. Correct the current implementation at its existing owners and supply the missing affected UI verification. This does not implement the original task's remaining setup, discovery/reset, console, mock/pages, linking/SSO or client-delivery cycles.
