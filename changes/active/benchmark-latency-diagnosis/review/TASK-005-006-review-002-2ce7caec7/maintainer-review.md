## Findings and calibration

No changed ownership, layout, type or method choice inspected here establishes a material maintainer violation or DRIFT. Removing shared schemas, named preparation reuse, retained serializer bytes, or the added lifecycle state would remove explicitly required behavior or restore measured repeated work. Moving those workflows to new services would increase responsibility overlap.

One bounded-cache implementation concern was examined: SchemaMap counts hash buckets when clearing, and concurrent first preparation of the same schema can retain duplicate equal entries after unlocked compilation. Subsequent lookups hit the retained entry, so this does not establish continuing growth under normal repeated calls. No source-backed supported-use consequence meeting this review threshold was established; no finding or remediation is proposed. A different private map representation, additional registry, or generalized cache would not be justified by that observation alone.
