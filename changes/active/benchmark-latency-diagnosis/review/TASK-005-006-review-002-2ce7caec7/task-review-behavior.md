## Runtime trace and reuse evidence

AgentExecutor resolves/binds a per-call Prompt, narrows citation slots by a deterministic name of the exact sorted identifier set, and shares PreparedSchemas. The loop renders once, retains one template, and rebuilds only conversation messages. Hooks receive a clone, so replacing model/schema/settings in one iteration does not mutate the next template. StructuredOutput selects the outgoing schema after the hook and continues validating each final answer; invalid answers keep bounded correction turns. Vala still decodes and validates declared Verdict and citations separately. Request borrowing removes ownership transfers, not response ownership or cancellation boundaries. Provider send/stream implementations retain serialization/retry and owned response-stream behavior.

SharedSchema extends the existing schema preparation owner, rather than adding a global registry or storing caller/evidence state. COW prevents a held schema identity changing. Render detaches only the response-schema field, round-trips the other native body and reattaches the schema, substituting it only when patterns are present. Named schema edits use the same preparation owner with exact input schema and deterministic edit name. The one production caller derives the name from sorted valid SlotName identifiers. No second judgment or bypass flag was introduced.

RequestJson::serialize reuses the existing kept-text owner; the written-text scanner indexes compact writer output and falls back to the existing decode/canonical path for duplicate members or excessive members. Existing parse remains responsible for arbitrary received bytes. The generic serializer has an explicit no-RawValue precondition; inspected production typed request bodies contain JSON Values/shared schemas, not RawValue. No supported violation of that precondition was found.
