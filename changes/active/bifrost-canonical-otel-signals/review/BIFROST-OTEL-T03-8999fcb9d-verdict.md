### FIND-BIFROST-OTEL-T03-1 — MAJOR: Trace detail silently succeeds with only the first 1,000 spans

- Closure verification: Add a trace with more than 1,000 spans but below the byte ceiling to the existing HTTP `pg_router_smoke` and gRPC service-test owners; both must succeed with every span.
