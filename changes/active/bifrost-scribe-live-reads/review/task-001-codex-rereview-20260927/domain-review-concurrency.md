## Prior findings and verification limits

The old CONC-002 blocking-poll path is closed by `StagedRunWindows`; the one protected read already in progress may finish after the leader cancels, but no next window is scheduled, and the staged lease remains until that read finishes. The staged cancellation proof is a Scribe-level unit test rather than a running-server journey. The server journey exercises cancellation/drop with memtable rows and backpressure beyond 30 seconds; the staged unit test exercises the precise in-flight blocking boundary.
