## Failure and recovery assessment

A dropped/blocked remote read owns references and reader leases, not durable publication authority. Before shutdown, ordinary backpressure retains those owners. On shutdown, accepted-IO failure reaches the connection independently of body polling, and dropping its body releases the fragment's native stream, scan leases, source references and receiving reservations. Scribe persistence and Forge settlement still drain through their existing server-owned lifecycle. Unsettled work remains replayable; connection termination is not a successful write ACK or successful query terminal.

Foreign/missing/duplicate tenant metadata is refused before that file decodes rows even on a cache hit. A remote lazy refusal now preserves its class through the open stream, avoiding the prior successful/degraded omission. Legitimate availability degradation remains a separate pre-row policy; no new exact acknowledged-write inclusion guarantee is inferred.
