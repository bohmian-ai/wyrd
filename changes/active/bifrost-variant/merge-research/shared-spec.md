## Open decisions for the human

1. **Should REQ-187 survive under REQ-036?** Main's REQ-187 (verified-change-contract rev 63, user-directed) stores the client emit time in `wyrd_event_time` for drift, eval, `record` and verify rows. OURS removes the column.
   - Drift and eval observations keep the property through `created_at`.
   - `observe.record` into a user dataset would carry no client emit time unless the table declares its own time column.
   - Verify rows use the server's `ended_at`.

   Recommendation: REQ-036 supersedes REQ-187, recorded as a revision of both specs. The REQ-187 journey `observations_store_the_client_emit_time` (wyrd-sdk-rust `observe_run`) gets rewritten to assert `created_at`.
2. **Compaction-core fork rev.** A new `bohmian-ai/iceberg-compaction` commit is needed with Arrow 60/DF 55.1 and the REST catalog dropped (hazard 3). That is external repo work. The other option is a time-boxed exception to the Ring ban, which needs an owner's call.
3. **REQ-037 lists a table main deleted.** Drop `vala.dev.agent_traces` from REQ-037 (`spec.md:1141`), because main removed the table in 1090580f2.
4. **Bench task name.** Decide which name survives: main's `bench:capacity` or OURS' `bench:bifrost:client-queue`. The `wyrd-queue/src/config.rs` doc follows that choice.
