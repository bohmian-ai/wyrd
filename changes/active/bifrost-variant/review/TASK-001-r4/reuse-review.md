## Confirmed duplicates

### REUSE-R4-001 — public per-instance JSON renderer duplicates the shared byte renderer

- New location: `crates/shared/wyrd-queue/src/variant.rs:219-231` (`EncodedVariant::to_json`).
- Existing owner: `crates/shared/wyrd-queue/src/variant.rs:234-249` (`variant_bytes_to_json`).
- Evidence: the method contains only `variant_bytes_to_json(&self.metadata, &self.value)`. Repository-wide caller counting found no production caller; its only callers are the two unit-test assertions at `variant.rs:791` and `variant.rs:861`. The shared free function is the real cross-boundary owner and is used by the Python and TypeScript native SDK projections as well as the Variant tests.
- Same job: both accept the same encoded metadata/value owned by `EncodedVariant`, call the same upstream `Variant::try_new(...).to_json_value()` path, and return the same `Result<Value, VariantViolation>`.
- Smallest consolidation: delete `EncodedVariant::to_json`; have the two unit-test assertions call `variant_bytes_to_json(encoded.metadata(), encoded.value())` (or build a column and use `variant_cell_to_json` where the test is about Arrow storage). Add no replacement method.
- Violated rule: `AGENTS.md` §15 requires reuse of the existing owner and forbids an added helper until the repository is shown not to provide the behavior. This wrapper is the per-case path beside the general path.
- Classification: `VIOLATION` (blocking).
