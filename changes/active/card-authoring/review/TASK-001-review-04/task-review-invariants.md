## Producer-to-consumer checks

Canonical comparison preserves child conflict detection because Graph visits a Card's current captures before looking up the parent. Consequently canonically equal parents cannot hide differing same-identity active children. The successful decode comparison excludes only diagnostic provenance; local source and extraction state remain comparison inputs. The fallback for malformed definitions cannot make them publishable: a retained malformed Card is subsequently decoded/refused during declaration.

The former split capture authority has been removed rather than supplemented. Local schema_ref setters use the same Body ownership as ordinary references. After a setter replaces schema_ref, only that field's current captures enter Graph; another live reference to the schema remains independently reachable. Artifact.file carries the existing converted reference value, so downstream code-source/workspace consumers no longer need to reconstruct or guess intent.

Singleton local admission deliberately runs each local descriptor through the existing loader separately. This preserves the sole-publication contract without combining independent external local roots into a fabricated graph. ReferenceSlotVisitor still checks unresolved paths and authored UIDs there. All descriptors and the remaining ordinary graph are admitted before Graph returns; Cards starts publication only afterward. This closes the demonstrated nested local-to-local, unresolved-path and cross-partition-identity failures. It does not assert a new automatic publication contract for arbitrary heavy-to-light dependencies, which the remediation explicitly excluded.

For a local root with local dependencies, dependency-first collection places that root last in artifacts. Its actual sole-publication receipt is therefore the receipt selected by Cards. A spec-only Artifact root remains in the ordinary canonical input and uses the usual root selection. Public owned/borrowed adapters carry the full Card, so neither path reconstructs JSON or discards metadata/source/extract. The state tail remains an ordinary consumer of the returned root and does not acquire a second publication owner.
