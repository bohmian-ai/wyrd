No second clone/index/rerank workflow was added.
- `CodeReviewMetadata` remains SnapshotStore and ContextStore. Existing SQL conditional pointer publication and context stamps are reused. A separate bounded queue inside the existing metadata owner is justified.

Single and batch paths use the same Completion input, and a replay under the same selected result reproduces the same fact. There is no second checkpoint or source payload in SQL.
