## Existing-owner assessment

The bridge adds a call origin to the existing server-hosted tools. It does not duplicate Card reads, Bifrost catalog/query authorization, Caller reconstruction, permission checks, audit staging, publication acceptance, or tenant object path validation. The existing owners remain necessary because they enforce capability-specific permissions and data semantics; replacing them with bridge-local checks would lose those boundaries. The added Dispatch owns the shared per-invocation allowance/records/concurrency required for the two origins; Invocation remains the one accepted-caller host boundary. No materially unearned security machinery was found.
