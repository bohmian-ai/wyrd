- **Location:** `crates/wyrd/wyrd-mcp/tests/bifrost/mcp/verification.rs:1547–1555` (`FrameAgent::submit`), explicit panic at `:1585–1588`.
- **Evidence/reachable consequence:** This helper is called by `grouped_frames_over_mcp_are_bounded` for real HTTP evidence uploads. There is no `# Panics` section. The new helper's failure contract is therefore incomplete and does not satisfy the explicit mandatory documentation gate. This is not a request to redesign upload handling or alter the test's assertions.
- **Smallest testable correction:** Document the rejected-upload panic on this helper in the same bounded documentation remediation, preserving behavior/assertion and existing Errors; alternatively consistently return the existing helper error for the refused upload and document that behavior.
