A successful later payload omission no longer needs a downstream guard because there is no later payload read. SQL/Arrow decoding remains appropriate at the query-result boundary. `GroupState::covers` and the outstanding fence still own rejudgment/serialization; they are not redundant value-completeness guards.

The remaining new owners earn their state: GroupPoller retains deployment query dependencies, BindingPoll retains one binding's authorized query and table availability, Sources owns shared slot/tuple invariants, and GroupRead/Payloads/Ended represent the selected evidence. No zero-state utility owner, single-implementation trait, generic resolver or speculative extension is required or proposed.
