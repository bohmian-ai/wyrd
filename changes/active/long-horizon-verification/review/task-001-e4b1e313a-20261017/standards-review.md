## Proposed material findings

### SR-001 — VIOLATION — new Rust documentation does not meet the explicit hard gate

- **Obligation:** AGENTS §16 requires rustdoc on every new/materially changed item, including private fields and modules, and `# Errors` naming conditions on every fallible method. Agent rules repeat this as `BLOCK_BEFORE_MERGE`; the task-review skill preserves this blocker even for documentation-only defects.
- **Exact source evidence:** `crates/wyrd-spec/src/card/trigger.rs:137–155`: new `TriggerDuration::fmt` has only “Writes the authored text” and no Errors section; new `Deserialize::deserialize` has only “Decodes and validates authored … text” and no Errors section although both string decoding and duration parsing can fail. `crates/wyrd-spec/src/card/verifier/reference.rs:185`: new `SourceText(String)` has no rustdoc for its private tuple field. `crates/wyrd/wyrd-server/src/verification/groups.rs:804–805`: new test module has no module rustdoc. `sdks/wyrd-sdk-rust/tests/integration/support/mod.rs:499`: new `Forward(UnboundedSender<Request>)` has no documentation for its retained sender field.
- **Consequence:** the immutable candidate fails an explicitly mandatory repository completion gate; generated formatting/lints do not cover private documentation completeness. A maintainer cannot get the new duration decode failure contract or the undocumented owners from their rustdoc.
- **Correction:** complete the missing rustdoc on these changed items in the same bounded remediation, including real Errors conditions for formatter write failure and non-string/malformed duration decoding. Review other added/materially changed items in this same write set for the same requirement; do not document unrelated old code, weaken the rule, or create a style-only follow-up round.
- **Focused closure:** inspect the corrected items and changed-item documentation, then run only the owning format/lint/docs checks required for that documentation write set. No new behavioral test or new documentation checker is necessary.
