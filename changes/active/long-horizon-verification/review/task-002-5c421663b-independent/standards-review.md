- Classification: **VIOLATION**.

It explicitly makes missing rustdoc a hard blocker. architecture/agent-rules.md repeats `BLOCK_BEFORE_MERGE`; maintainer-style's Documentation section supplies the same rule.
- Exact locations: `crates/wyrd-spec/src/envelope.rs:752–759`: new `decode` (signature line 755) and materially changed `spec_from_kind_value` (signature line 759).
- Evidence: decode's three-line doc describes field paths but has no Errors section despite returning Result. spec_from_kind_value now routes all fourteen native Card kind decodes through path-aware deserialization and returns an explicit External error, but has no rustdoc at all. The shared operation is reached from Card deserialization and Spec::from_kind_and_value; the added contract test uses that public conversion. This is the repository's express documentation blocker even if generated artifacts, compilation and tests pass.

Give spec_from_kind_value substantive workflow/operation documentation and Errors conditions (unsupported External or invalid kind-specific body), describing its existing preprocessing without changing it.
