## Invariant traces

- **Accepted authority:** authentication produces a token-free `Caller`; create authorizes/audits it and installs it in `Preparation`; exact graph pinning and suitability finish before acceptance; gateway and tool adapters reuse its tenant, effective principal, scopes, credential attribution, and delegation; each resource owner performs its own decision; replay never replaces it; terminalization drops the prepared dependencies.
- **Run state and idempotency:** `admit` creates one scoped key, slot, cancellation child, outcome channel, and tracker token under the table lock; preparation is process-owned; `Reservation::accept` atomically converts preparing state into one queued run; whole nonterminal snapshots replace whole; query owners drain; `AcceptedRun::finish` installs the sole terminal snapshot, timestamps retention, releases active capacity, and sweeps the run and key together.
- **Query ownership:** the Agent waiter starts a tracked owner and holds only its result wait; dropping the waiter signals cancellation; the owner retains stream and settlement through the original deadline; terminal/protocol/EOF proof is validated before any result returns; Workflow terminal commit follows the owners' drain. MCP is the sibling consumer of `BoundedQuery`, and scheduled queries share `RunningQueryControls::open_cancellable`.
- **Provider identity:** authored YAML/JSON produces an adjacent-tagged `ProviderRequest`; Cards persist that tag; Prompt transforms deserialize back into the named variant; Workflow hydration retains it; the in-process gateway projects by variant, so the Gemini-shaped Vertex body remains Vertex from source through the Vertex adapter and response decoder.
- **Analytical lifecycle:** the leader owns participant grant streams; dropping them is release; followers observe close and asynchronously settle their own graph. The leader joins its own attempt/exchanges and does not wait for a follower acknowledgement. Journeys may wait for observable follower cleanup before asserting baseline without adding a production release protocol.
