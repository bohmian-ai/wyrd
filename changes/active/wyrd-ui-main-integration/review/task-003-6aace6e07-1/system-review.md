## R5 closure and limits

FIND-003-11's residual cause was conversion before policy: original invalid JS numbers could become permitted u32 values. Native now extracts f64, losslessly parses an exact u32 in `parse_ceiling` (`lib.rs:1566`), then reuses shared range admission. Fractions, non-finite and out-of-u32 values cannot become allowed budgets; zero still reaches and fails shared range admission. Both originals and effective budgets are checked without a second host policy. The implementation leaves public JS number signatures, omitted defaults, output-overflow behavior, terminal validation, cancellation notification and existing protocol error envelopes intact. The early take/drop ordering closes the stream on this new failure path rather than relying on wrapper `return()` after the wrapper marks itself done.
