## Caller-to-result and root-cause audit

The shared renderer is the sole layout lifecycle owner. Production callers are the gallery, example `/view` route and exported `mountView`; the MCP App uses mountView. Direct custom Svelte hosts are supported through the published WyrdView export. All consume the same PanelSchema and rendering/edit logic. No additional host-specific layout store, persistence or data loader was added.

An authored panel passes strict document geometry validation, then the renderer combines its layout with completed/draft local edits. Pure place resolves occupancy without changing authored values. Placements feed CSS and, below the breakpoint, presentation ordering. Editing starts from resolved coordinates, applies the shared pure bounded edit, and commits all retained edits into a new callback document. Handler echo resets local state to the written layout while the content signature prevents read churn. A new authored value or reference ends the old gesture and discards local overlays. Scope remains document layout; the renderer does not acquire server workflow authority.

R4 addresses the first point where independently scheduled current placements and effect-owned loaded rows are joined: narrow `ordered`. Filtering by current placement membership removes outgoing-only IDs before coordinate dereference, then sorting a newly allocated array preserves the original loaded collection and stable tie order. Current invalid-panel rows have an ID from the same parsed list as placements, so they remain eligible even without props. Current loading, denied and failed rows likewise survive. Existing start/abortAll/settle still abort outgoing reads and reject late settlement; no load runs during a derivation and no additional generation owner is introduced. Wide rendering is unchanged.

The existing alternatives were checked: start already owns IO and cancellation; placements already names the current identity set; pure place owns geometry only. Neither moving loading into a pre-effect nor adding a host remount or ID restriction is needed. Native Array.filter/sort and Map.has are sufficient. The retained membership guard belongs at this consumer because this join itself creates the cross-generation invariant. It does not hide a malformed authored document or duplicate upstream validation.

Prior remediation introduced full authored value observation alongside reference tracking. That is necessary to honor already accepted native Svelte nested updates while keeping layout-independent reads; reusing the same parsed result and native derived/effect facilities avoids a parallel parser or deep-observer framework. The pure geometry file isolates real shared pointer/keyboard/render geometry; no new abstraction, dependency, config or speculative surface needs deletion to satisfy TASK-027.
