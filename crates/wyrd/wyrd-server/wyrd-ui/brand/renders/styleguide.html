Rules

the non-negotiables · geometry never changes with mode, viewport, or altitude

Geometry

  • Radius 5px, locked. True circles only for dots and avatars.
  • Borders 2px normal, 3px hero, 2px dashed inside cards. Always present.
  • Shadows hard-offset, zero blur: 3px quiet, 6px raised, 10px loud.
  • No blur, glassmorphism, soft elevation, or glow.

Colour

  • Blue is primary — Wyrd's identity, links, selection, the one strong action.
  • Lime is secondary — Fathom surfaces, the client plane, second-voice emphasis.
  • Bright lime is a fill only: 1.30:1 on white. Use --lime-text for text and bars.
  • Heat ramps use --brand-strong; lime cannot darken on white.

The Line

  • Lime = client / runtime, mode-split so it survives a light surface.
  • Amber = server / enterprise.
  • Steel = control / deploy. Close to brand blue — never a stand-in for it.
  • Applied as a 3px left-bar, always beside a text label.

Signal

  • Accent is signal, never decoration.
  • Status overrides kind — an alerting panel's top-bar turns danger.
  • Never colour alone. ok and danger collapse to 1.11:1 under deuteranopia, so status carries a glyph and thresholds carry a tick.
  • Foreground is frozen for hours-long readability. Do not re-tune.

What this system dropped

recorded so nobody re-adds it by accident
  • The arcade register. Press Start 2P, VT323, the --sky-*/--grid/--star/--spr-d scene tokens, ordered dither, 8-bit notch corners, the pixel agent portrait.
  • Brand violet. --rune* is gone — renamed to --brand* and revalued to blue.
  • Archivo Black. Replaced by Space Grotesk 700, which holds up better at KPI sizes.
  • wordmark.svg. The wordmark is typeset, not an asset — and the old file was off-palette.
  • The rune button variant. primary is blue now; the second slot belongs to fathom.
