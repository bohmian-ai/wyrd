00

Rules

non-negotiable

This file is the canonical reference for Mitari UI theming, paired with theme.css. Same geometry in light and dark; only palette and atmosphere change. When a styling question comes up, this is the answer.

Geometry

Radius 5px on every surface and control. 2px ink borders (3px for hero/feature containers), 2px dashed for dividers inside cards. Borders are always present — never gray, hairline, or low-contrast.

Shadows

Hard-offset, zero blur only: 3px quiet cards, 6px raised/stat, 10px hero block. No blur, no glassmorphism, no soft elevation, no glow.

Foreground · locked

Body text is #14141a light (~15:1) and #d6d6dc dark (~12:1). Dark is a calm off-white, not near-white — frozen, no more retuning.

Accent = signal

Lime and rune are signal, not decoration. They mark the selected row, active filter, primary action, status, semantic left-bars — never a default text color or a wash of background.

Altitude

Two registers that never bleed. Quiet is the workbench default — calm, 3px shadows, restrained accent. Loud is hero/landing only — 10px shadows, block hero, tricolor rail, big type.

Data viz

Charts are brutalist too: 2px ink frames, flat fills (no gradients/glow), bars and ticks in semantic colors, axes & gridlines in border ink (gridlines faint-dashed). Series read by The Line — lime/amber/blue — with rune & danger for non-semantic lines. Sequential/heat ramps use violet, never lime (lime can't darken on white).

Span kinds

Trace span colors are fixed: agent=lime, llm=violet, tool=amber, retrieval=blue, error=red. Waterfall bars are tinted-fill + 2px kind border; status is a green/red dot. The same kind ticks key every trace table.

Detail panels

Drilldown drawers are raised altitude — 6px shadow, a 4px kind top-bar. The top-bar carries the row's kind (llm=violet, eval=rune…) unless the panel is in an alert state — then status wins (drifted → red). Metric bars color green/red by threshold.

Never

No 1px hairlines, no gray borders, no blurred/soft shadows, no glow or CRT scanlines, no purple card_ref column, no layered-offset CTAs. These were all tried and cut.

01

Palette

every allowed token

The complete token set. Every value has a light and a dark resolution. The Line encodes the product: lime = client/runtime, amber = server/enterprise, blue = control/deploy.

02

Structure

geometry & anatomy

The physical system: the radius, the border weights, the shadow dial, the semantic left-bar, and a fully anatomized card. Same in both modes.

03

Quiet

workbench · default

The analytics surface a developer lives in for hours. 2px ink borders, one 3px shadow per card, white headers, calm fields, accent only on the selected row + active filter + status + semantic bars. This is the default register — registry, tables, detail, forms, settings.

04

Analytics

data viz · workbench

The workbench is fundamentally an analytics surface. These are the data primitives in the locked style: KPI tiles with sparklines, bar and line charts, a distribution bar, an activity heatmap, an expandable storage/card tree, and a dropdown filter. All flat, all 2px-framed, all token-driven — quiet register.

05

Traces

observability · the workbench core

The most important workbench surface: inspecting agent & LLM execution. Scope + time-range toolbar, a dense KPI rail (requests, error rate, p50/p95/p99, spend, tokens), latency/throughput/error charts, a recent-trace list, and the signature span waterfall — nested spans on a shared timeline, colored by kind, with status and duration. Breakdowns by operation, model, and error type close it out. Quiet register throughout.

06

Panels

drilldown drawers

The detail drawers that open when you select a row: a span (from the waterfall), an eval record (agent evaluation), and a drifted feature (traditional drift). Raised altitude — 6px shadow + a 4px kind top-bar — overlaying the workbench. The drift panel's top-bar is red because status overrides kind when a panel is in an alert state.

07

Loud

hero / landing only

Top-of-page and marketing only. Block-with-shadow hero, tricolor rail, 10px/6px shadows, big display type, the solid lime CTA. It earns attention precisely because the workbench refuses to compete.

08

Arcade

attract mode · exploratory

Mitari ≈ Atari. An opt-in retro register built entirely from locked primitives — a pixel display face, the runic “fuji” mark, ordered-dither texture (stepped, zero-blur), and notched cabinet corners. It still obeys every rule: 5px radius on real controls, 2px ink borders, hard-offset shadows, no glow, no scanlines. The boldness is the point — the arcade skin just makes it grin. Loud-adjacent: use for landing moments and launch screens, never beside the workbench.
