# Agent

An `Agent` declares and runs one bounded loop over a `Prompt`, tools, callbacks,
session memory, and run config. Provider and model identity live on the prompt;
the agent owns execution policy and runtime-local tools.

## Envelope

```yaml
apiVersion: wyrd/v1
metadata:
  space: default
  name: planner
  version: "0.1.0"
kind: Agent
spec:
  prompt:
    provider: openai
    model: gpt-4o-mini
    messages:
      - role: user
        content: "Plan: ${topic}"
```

## Python

```python
from wyrd import Agent, Prompt

agent = Agent(
    name="planner",
    version="0.1.0",
    prompt=Prompt(provider="openai", model="gpt-4o-mini", messages=["Plan: ${topic}"]),
)
run = agent.run({"topic": "Rust"})
print(run.output)
```

Constructor: `Agent(*, prompt, name=None, version=None, space=None, id=None,
tools=None, run_config=None, before_agent_callback=None,
after_agent_callback=None, before_model_callback=None,
after_model_callback=None, before_tool_callback=None,
after_tool_callback=None, session=None, labels=None, annotations=None,
provider_base_url=None, provider_api_key=None, output_type=None)`.

`Agent.run(input, *, session_id=None, output_type=None) -> AgentRun` accepts a
string or mapping. Callbacks can replace requests/responses or abort inline
behavior. Observers are not installed on `Agent`; wrap a solo agent in
`Workflow.sequential("solo", agent, observers=[...])`.

## AgentRun

`AgentRun` exposes `output`, `finish_reason`, `iterations`, `tokens_in`,
`tokens_out`, `conversation`, `error`, `structured_output`, `parsed`, and
`provider_response`.

`structured_output` is a `dict[str, Any] | None` when the prompt declares
`output=...`. `parsed` is the typed object produced by `output_type=...`.
`provider_response` is the final typed provider wire wrapper.

## FinishReason

Values: `ModelStopped`, `MaxIterations`, `CallbackAborted`, `ProviderError`,
`ToolError`, `Timeout`.

## Tool Delegation

`agent.as_tool(description=None)` returns a runtime-local delegate tool that
routes through the same bounded loop.

## Save And Load

`agent.save(path)` materializes the local card envelope. `Agent.from_yaml(path)`
hydrates it. Save/load are local filesystem operations only; registration is
owned by registry/client surfaces.

Snapshot getters such as `agent.prompt` and `agent.tool_names` return the
current resolved prompt and runtime-local tool names.
