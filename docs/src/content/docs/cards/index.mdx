# Cards

This section is anchored by generated pages from `crates/wyrd-spec/schemas/`. The generated pages are intentionally plain: source schema, field table, and authoring notes.

Run `mise run docs:generate` after changing card schemas.

## Authoring model

Start with the card kind, then choose the spec fields that make the card useful at runtime. A card should be understandable without reading the implementation that consumes it.
