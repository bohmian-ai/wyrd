# CLI and MCP

This section is reserved for the command-line and MCP surfaces. Public commands should be documented through repository tasks while the implementation is still landing.

## Documentation rule

If a command is not available yet, document the intended contract and say that the concrete command lands in a later phase. Do not invent a working command.
