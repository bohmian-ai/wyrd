# Cards

A card is the durable record for a Wyrd asset. It should answer four questions without a side conversation:

- What is this?
- Which typed spec describes it?
- What other records does it depend on?
- Which rules apply when it is used?

Cards are intentionally boring. Their value comes from being stable enough for humans, services, and agents to rely on.
