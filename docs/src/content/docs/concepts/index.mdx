# Concepts

<Aside title="TL;DR" data-variant="wyrd">
Wyrd is seven primitives: **Card**, **Spec**, **Run**, **Observation**, **Policy**, **Audit**, **Lineage**. **Service** is a Card kind that packages the rest into a deployable unit.
</Aside>

<dl class="wyrd-defs">
  <dt data-kind="model">Card</dt>
  <dd>The durable, versioned envelope for one thing Wyrd governs.</dd>

  <dt>Spec</dt>
  <dd>The typed payload inside a Card. One schema per kind.</dd>

  <dt>Run</dt>
  <dd>The record of an execution tied to a specific Card version.</dd>

  <dt data-kind="experiment">Observation</dt>
  <dd>A structured behavioral signal attached to a Run.</dd>

  <dt>Policy</dt>
  <dd>A decision rule evaluated when Cards are written or Runs are created.</dd>

  <dt>Audit</dt>
  <dd>An immutable entry describing who or what made a decision.</dd>

  <dt>Lineage</dt>
  <dd>The typed graph that connects Cards to Cards, and Cards to Runs to Observations.</dd>

  <dt data-kind="service">Service</dt>
  <dd>A Card kind that packages the other primitives into a deployable unit.</dd>
</dl>

<Aside title="What this isn't" data-variant="not">
Cards are **not** file-system artifacts, ORM rows, or git blobs. They are typed, versioned records Wyrd owns end-to-end.
</Aside>
