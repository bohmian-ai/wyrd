# Concepts

Wyrd keeps the vocabulary small on purpose. Cards identify durable things. Specs describe those things. Runs record execution. Observations explain behavior. Policies decide what is allowed. Audit records explain who or what made a decision.

Read this section before adding a new object type or public API.
