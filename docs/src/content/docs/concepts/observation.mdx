# Observations

An observation is a structured signal about behavior. It can describe a trace, a drift result, an evaluation score, a service health event, or another runtime fact that belongs with a card or run.

Observations should be tied to stable identifiers. If a signal cannot be traced back to the asset or action that caused it, it is harder to use for remediation.
