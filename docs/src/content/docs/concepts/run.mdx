# Runs

<Aside title="TL;DR" data-variant="wyrd">
A Run is the record of an execution tied to a specific Card version. Cards say what should exist; Runs show what happened.
</Aside>

<dl class="wyrd-defs">
  <dt>Target</dt>
  <dd>The exact Card and version this execution was bound to.</dd>

  <dt>Inputs/Outputs</dt>
  <dd>What flowed in, what came back, and whether it matched the Spec.</dd>

  <dt>Status</dt>
  <dd>Started, succeeded, failed, or cancelled.</dd>

  <dt data-kind="experiment">Observations</dt>
  <dd>Structured behavioral signals emitted during or after the Run.</dd>
</dl>

Runs are the bridge between declaration and behavior. Without a Run reference, Observations and Audits have no execution to anchor against.

<Aside title="What this isn't" data-variant="not">
A Run is **not** a log line. It is a durable record the registry can trace to a Card version, an actor, and a chain of Observations.
</Aside>
