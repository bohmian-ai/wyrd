# Specs

A spec is the typed payload behind a card. It carries the fields Wyrd can validate and use for runtime behavior.

Specs should hold operational truth: inputs, outputs, adapters, budgets, runtime policy, policy references, and dependency references. Free-form notes are useful for context, but they should not be the only place a runtime rule exists.
