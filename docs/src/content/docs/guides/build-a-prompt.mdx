# Build a Prompt

A Prompt declares provider, model, system instruction, user messages, template variables, and optional structured output. It is the durable contract an Agent runs against.

## Variables

`${name}` and `{{name}}` both bind template variables. Prefer `${name}` in Python code and `{{name}}` in YAML. The prefix `${media:name}` is reserved for media inputs.

<Tabs>
  <TabItem label="Python">

```python
prompt = Prompt.openai_chat(
    "gpt-4o-mini",
    messages=["Plan the release for ${topic}."],
    variables=["topic"],
)
```

  </TabItem>
  <TabItem label="Rust">

```rust
let prompt = openai_chat(
    "gpt-4o-mini",
    OpenAiChatOptions {
        messages: vec!["Plan the release for {{topic}}.".to_owned()],
        variables: vec!["topic".to_owned()],
        ..OpenAiChatOptions::default()
    },
)?;
```

  </TabItem>
</Tabs>

## Structured Output

Structured output accepts a dict of Python types, a Pydantic-style output class, or raw JSON Schema. `Prompt(output={"summary": str, "steps": list[str]})` extracts JSON into `AgentRun.structured_output`; `output_type=Plan` extracts into `AgentRun.parsed`.

## System Prompt

Put stable instruction text on the Prompt. The Agent runs the Prompt; it does not override provider, model, or system instruction.

<Tabs>
  <TabItem label="Python">

```python
Prompt(
    provider="mock",
    model="mock-model",
    system="Plan concise next steps.",
    messages=["Plan: ${topic}"],
)
```

  </TabItem>
  <TabItem label="Rust">

```rust
OpenAiChatOptions {
    system: Some("Plan concise next steps.".to_owned()),
    messages: vec!["Plan: {{topic}}".to_owned()],
    ..OpenAiChatOptions::default()
}
```

  </TabItem>
</Tabs>

## Provider And Model Identity

Provider and model live on the Prompt. The Agent owns execution policy, callbacks, tools, and session memory. Multi-provider routing is not part of this stage.
