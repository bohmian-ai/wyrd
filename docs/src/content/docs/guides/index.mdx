# Guides

Guides show the intended developer workflow around Wyrd surfaces. They should be
runnable when the surface exists, and explicit about ownership boundaries when a
later service owns part of the lifecycle.

## Current guides

- [DataCard local workflow](/guides/data-card-local-workflow/) - create a DataCard, save it locally, load it back, and inspect the files.
- [Register a card](/guides/register-card/) - registry-oriented card registration guidance.
- [Lock and install a service](/guides/lock-install-service/) - service install flow guidance.
