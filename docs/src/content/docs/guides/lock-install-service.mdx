# Lock and install a service

A service should be locked before installation when reproducibility matters. The lock records the resolved components and runtime policy so the install step does not depend on hidden state.

## Flow

1. Register or update the service card.
2. Resolve the service lock.
3. Review the locked components and runtime policy.
4. Install from the lock.
5. Record the install outcome as a run or audit event.

Later phases will attach the concrete CLI and Python commands to this flow.
