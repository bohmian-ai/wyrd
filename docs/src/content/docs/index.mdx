## One platform, four jobs

<dl class="wyrd-defs">
  <dt data-kind="service">Security</dt>
  <dd>Policy as code. Immutable audit. Lineage from model to deployment. Auditor-ready in week one.</dd>

  <dt data-kind="model">Infra</dt>
  <dd>A real inventory of every model, prompt, agent, and service in production. Versioned, owned, locked.</dd>

  <dt data-kind="prompt">Data Science</dt>
  <dd>One standard path from notebook to deployment. Same envelope for every artifact.</dd>

  <dt data-kind="experiment">Observability</dt>
  <dd>Evals, drift, and behavior in a unified view. Every signal ties back to a Card version.</dd>
</dl>

## What exists today

JSON Schemas for all 18 Card kinds. Runtime, telemetry, and testing crate shells; behavior lands in Phase 5a. Generated reference pages for every Card kind, the OpenAPI surface, and the error catalog.

CLI, Python SDK, HTTP routes, and MCP tools land in later phases. Pages for those surfaces exist already and name the phase that fills them in.
