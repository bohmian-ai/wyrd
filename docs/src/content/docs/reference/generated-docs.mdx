# Generated docs

Generated docs are produced from repository metadata:

- Card pages come from `crates/wyrd-spec/schemas/`.
- API summary pages come from `openapi.yaml` and the schema inventory.

Refresh generated pages with:

```sh
mise run docs:generate
```

Check the generated output before committing it. If generated pages drift, change the source schema or generator instead of hand-editing generated content.
