# Start here

Use this section to get oriented before writing code or asking an agent to change the repository.

## First read

- Read the card model before adding a new public concept.
- Read local development before running checks.
- Read the agent guide before delegating repository work.

## Working rule

When docs and code disagree, treat the code as the source of truth and update the docs in the same phase. The docs gate exists to keep that habit visible.
